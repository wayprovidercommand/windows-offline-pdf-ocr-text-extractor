## Privacy and Local Processing

The documented workflow is built around local Windows file processing rather than uploading source files to a public web converter. Do not post private documents, recordings, photos, transcripts, or extracted text in public GitHub issues. Remove confidential information from screenshots and logs before sharing them.

## Recommended Workflow

- Keep original files in a separate backup folder.
- Test one representative file before running a large batch.
- Review generated output before replacing any source data.
- Use a clearly named output folder.
- Check timestamps, OCR text, subtitles, transparency, metadata, or image quality where relevant.

## Troubleshooting

- Use clear scans at adequate resolution for better OCR.
- Rotate or deskew sideways pages before recognition when needed.
- Always proofread names, numbers, and important text.
